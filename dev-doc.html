Документация для верстальщика — учёттепла.рф

Концепт «Комплекс-Техно». Источник — код принятых страниц в concept/ (HTML, css/*.css, js/*.js) и замеры в Chromium; не планы и не макеты. Где код расходится с правилами или Figma — это записано в разделе 8. Блоки кода — реальные фрагменты с путём и строками; кнопка «Копировать» кладёт в буфер ровно то, что показано.

1. Обзор

Концепт — набор статических HTML-страниц без сборщика. Один общий CSS-каскад (concept.css) + по одному-два дополнительных файла на тип страницы; JS — без библиотек. Эталон — принятые страницы из concept/; всё, что ниже, взято из их кода и замеров.

1.4. Внешние запросы, спрайт иконок, что не переносить

  • Шрифты. В <head> каждой страницы — fonts.googleapis.com (Sofia Sans Extra Condensed 100–900 и Inter 100–900). Для боевого сайта — подключить локально; реально используются: Sofia Sans Extra Condensed 400, 700, 800; Inter 400, 500, 600 (остальные начертания из ссылки не нужны — проверено по computed-значениям на всех страницах).
  • Иконки интерфейса — inline-спрайт <svg width="0" height="0"><symbol id="…"> в начале <body> каждой страницы (на Главной 28 символов), вызов <svg class="ic"><use href="#chev2"/></svg>. Спрайт надо перенести целиком в общий шаблон.
  • Только для концепта — не переносить: прелоадер (.preloader, html.is-preload), шторка перехода между страницами (.page-veil, html.is-page-in/-out), переключатель акцента (setAccent, .concept-bar — в разметке принятых страниц его уже нет, остались стили и функция), режим ?shot / html.is-shot, закреплённые «Этапы» .hs-* и .sv-tape из ранних версий. Блоки в concept.js помечены комментариями с датой.
